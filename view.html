🔋 – waiting for phone

Connect your phone

  1. Phone on the same Wi‑Fi as this Mac. Scan the QR code with the camera app, or open in Chrome.
  2. First time only: Chrome shows a security warning. Tap Advanced → Proceed. It's this Mac's own certificate.
  3. Allow the camera, point it at what you want to watch, tap Start streaming. Keep the phone plugged in.
  4. Tip: in Chrome's ⋮ menu choose Add to Home screen so it's one tap next time.
To stop, just close this tab. The server shuts itself down about 20 seconds later.

See and control the phone screen

Checking…

One-time setup on the phone:

  1. Turn on Developer options: Settings → About phone, tap Build number 7 times. On Samsung it's under Software information.
  2. Go to Settings → System → Developer options and turn on Wireless debugging.
  3. Tap Wireless debugging → Pair device with pairing code. Type what it shows here:
  4. It usually connects by itself a few seconds later. If not, type the IP address & port from the main Wireless debugging screen. It's a different port from the pairing one.
A USB cable works too: plug in, then tap Allow USB debugging on the phone.
The screen opens in its own window. Click to tap, scroll to swipe, and type with your keyboard. ⌘C / ⌘V share the clipboard both ways while it's open.
The camera pauses while another app is in front on the phone, and picks up again when you go back to the phoneOnDesk tab.
Wireless debugging turns off if the phone restarts or changes Wi‑Fi. Turn it back on and it reconnects without pairing again.
